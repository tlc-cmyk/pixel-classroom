# 像素課室（Pixel Classroom）

香港中學 ICT 電腦室像素場景 — 給老師 **Lap Cheung Tsao** 的 cozy 16-bit 課室模擬。

**口號：** 上課，像玩遊戲一樣

## 開啟

直接用瀏覽器開啟 `index.html`（離線單檔，無需伺服器／CDN）。

GitHub Pages：https://tlc-cmyk.github.io/pixel-classroom/

（若見舊畫面，請強制刷新：Ctrl/Cmd+Shift+R）

## 畫布

- 邏輯解析度：**640 × 360**
- CSS 約 2× 放大，`image-rendering: pixelated` + `imageSmoothingEnabled = false`
- **嵌入式像素圖集（atlas）**：程序高保真繪製後編成 PNG，以 base64 data URI 寫進單一 HTML（離線、無 CDN、無外部圖檔請求）

## 美術升級（本版）

- 木紋地板 4 變體錯縫鋪貼、牆面飾條、門、三扇窗（天空／雲／草木）
- 白板＋粉筆托盤、海報、地毯討論區、圓桌、多色書架、儲物櫃、盆栽
- 9 張電腦桌（螢幕 IDE 線條／鍵盤／滑鼠／椅）、講桌（茶杯＋文件＋筆）
- 老師 4 向 × 4 幀步行精靈；7 位坐下學生 + 1 位討論區走動；小貓趴睡／走路
- 窗光暖色光暈 + 四角 vignette

## 操作

| 按鍵 / 操作 | 功能 |
|---|---|
| Space / Enter（或點擊） | 標題畫面進入課室 |
| WASD / 方向鍵 | 移動老師角色 |
| 點擊／觸碰區域 | 顯示區域資訊面板 |
| 1–4 | 高亮並開啟：講授區、電腦區、討論區、儲物區 |
| Esc | 關閉面板 |

## 區域

1. **講授區** — 白板、講解
2. **電腦區** — 學生電腦桌、SBA／練習進度
3. **討論區** — 地毯＋小組圓桌
4. **儲物區** — 書架與櫃

底部 UI：節次（中四 ICT）與「進行中任務」晶片。

## 技術備註

- 單一 `index.html`，適合 GitHub Pages 根目錄部署
- `assets/atlas.png` + `atlas.json` 為圖集源檔（可選；執行期只用 HTML 內嵌 data URI）
- 簡易矩形碰撞（牆／桌／架）
- 離線、無 CDN、繁體中文 UI

## 限制（誠實說明）

- 圖集由程序像素繪製編成，**仍不及手繪 Aseprite／專業 pixel artist 逐幀畫的細緻度**（輪廓、材質抖色、角色表情與道具可讀性仍有差距）
- 非完整課程系統，僅氣氛／導覽場景
- 無存檔、無音效、無多人
- 觸控僅支援點擊區域；移動仍以鍵盤為主
