# 像素課室（Pixel Classroom）

香港中學 ICT 電腦室像素場景 — 給老師 **Lap Cheung Tsao** 的 cozy 16-bit 課室模擬。

**口號：** 上課，像玩遊戲一樣

## 開啟

直接用瀏覽器開啟 `index.html`（離線單檔，無需伺服器／CDN）。

GitHub Pages：https://tlc-cmyk.github.io/pixel-classroom/

（若見舊畫面，請強制刷新：Ctrl/Cmd+Shift+R，或手機清除網站資料）

## 畫布（直式手機全螢幕）

- 邏輯解析度：**360 × 640**（約 9:16 portrait）
- CSS：`100vw` × `100dvh`／`100svh`，含 `safe-area-inset`，**無 letterbox 黑邊浪費**
- 桌面寬螢幕：居中直式機框預覽
- **嵌入式像素圖集（atlas）**：base64 data URI 寫進單一 HTML（離線、無 CDN）

## 直式課室佈局

由上而下垂直堆疊，傢俬／角色放大方便手機閱讀：

1. **講授區** — 白板、講桌
2. **電腦區** — 2×3 大型電腦桌
3. **討論區** — 地毯＋小組圓桌
4. **儲物區** — 書架與櫃

## 觸控（手機優先）

| 操作 | 功能 |
|---|---|
| 大「開始上課」按鈕 | 進入課室 |
| 左下虛擬 D-pad | 移動老師 |
| 右下「互動／關閉」 | 開／關區域資訊 |
| 點擊區域 | 顯示資訊卡（卡在下半部，拇指可及） |
| WASD／方向鍵（桌面） | 移動 |
| 1–4／E／Esc（桌面） | 區域高亮、互動、關閉 |

## 角色與移動（專業 top-down）

- **Minimal Pixel Art 臉**：老師／學生／貓以程序繪製 16×24／16×12，對稱眼睛＋簡潔嘴巴，無畸形比例
- **狀態機**：`idle` / `walk`；四向面向（下／左／右／上）
- **步行週期**：動畫幀與實際位移同步（stride），卡住時不空踏
- **公平 AABB**：腳底碰撞盒 vs 傢俬底座；X／Y 分離解析，不會穿桌滑過
- **鏡頭**：直式 360×640 畫面軟跟隨老師（look-ahead＋邊界夾緊）

## 技術備註

- 單一 `index.html`，適合 GitHub Pages 根目錄部署
- 傢俬仍用內嵌 atlas；角色改為程序像素繪製（離線、無 CDN）
- 離線、繁體中文 UI

## 限制

- 角色為 clean minimal 風格，非手繪 Aseprite 高細節
- 非完整課程系統，僅氣氛／導覽場景
- 無存檔、無音效、無多人
