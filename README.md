# 像素課室（Pixel Classroom）

香港中學 ICT 電腦室像素場景 — 給老師 **Lap Cheung Tsao** 的 cozy 16-bit 課室模擬。

**口號：** 上課，像玩遊戲一樣

## 開啟

直接用瀏覽器開啟 `index.html`（離線單檔，無需伺服器／CDN）。

GitHub Pages（推送後）：https://tlc-cmyk.github.io/pixel-classroom/

## 畫布

- 邏輯解析度：**640 × 360**
- CSS 放大約 2×，`image-rendering: pixelated` + `imageSmoothingEnabled = false`
- 全部程序化像素精靈，無外部圖片

## 操作

| 按鍵 / 操作 | 功能 |
|---|---|
| Space / Enter（或點擊） | 標題畫面進入課室 |
| WASD / 方向鍵 | 移動老師角色 |
| 點擊／觸碰區域 | 顯示區域資訊面板 |
| 1–4 | 高亮並開啟：講授區、電腦區、討論區、儲物區 |
| Esc | 關閉面板 |

## 區域

1. **講授區** — 白板、講解
2. **電腦區** — 學生電腦桌、SBA／練習進度
3. **討論區** — 小組圓桌
4. **儲物區** — 書架與櫃

底部 UI：目前節次（中四 ICT）與「進行中任務」晶片。

## 技術備註

- 單一 `index.html`，適合 GitHub Pages 根目錄部署
- 簡易矩形碰撞（牆／桌／架）
- 學生有坐下與慢走兩種；桌上可選小貓

## 限制

- 非完整課程系統，僅氣氛／導覽原型
- 無存檔、無音效、無多人
- 觸控僅支援點擊區域；移動仍以鍵盤為主
